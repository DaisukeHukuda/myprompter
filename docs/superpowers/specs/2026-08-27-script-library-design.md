# myprompter — 原稿リスト（保存・履歴）機能 設計書

- 日付: 2026-08-27
- 承認: 福田さん（会話内で設計承認済み）
- 目的: 複数の原稿を保存し、リストから選んで切り替えられるようにする。更新順のリストが「履歴」を兼ねる。

## 決定事項

- **ファイル方式**: 「保存」ボタンは作らない。編集は選択中の原稿に自動保存（現行のデバウンス300msを踏襲）
- **リスト表示**: 更新が新しい順。表示名は「原稿の1行目（先頭20文字程度）＋更新日（M/D）」。空の原稿は「（無題）」
- **名前変更**: 専用UIなし。原稿の1行目を書き換える＝名前が変わる
- **設定の扱い**: スピード・文字サイズは全体共通のまま（原稿ごとに持たない）
- **やらないこと（YAGNI）**: 編集履歴（過去版への復元）、クラウド同期、原稿のエクスポート、件数上限管理

## UI（編集画面のみ変更。プロンプター画面は変更なし）

タイトル「myprompter」の下に1行追加:

```
[原稿セレクト ▼（更新が新しい順）] [＋ 新規] [🗑 削除]
```

- **セレクト変更**: 現在の編集内容を保存（デバウンス中ならフラッシュ）→ 選択した原稿を読み込んで表示
- **＋ 新規**: 空の原稿を作成して選択、textareaにフォーカス
- **🗑 削除**: `confirm()` で確認 → 選択中の原稿を削除 → リスト先頭（最新）を選択。最後の1件を削除した場合は空の新規原稿を自動作成
- ボタンはタッチしやすい高さ44px以上

## データ構造（localStorage）

- `myprompter.docs`: `[{ id: string, text: string, updatedAt: number }]` のJSON
  - タイトルは保存しない（表示時に text の1行目から導出）
- `myprompter.currentDocId`: 選択中原稿のid
- id は `Date.now().toString(36) + ランダム英数` で生成
- 既存キー `myprompter.script` / `myprompter.speed` / `myprompter.fontSize` のうち、speed/fontSize は現行のまま

## 移行（初回起動時）

1. `myprompter.docs` が存在すればそれを使う
2. 存在せず `myprompter.script` があれば、その内容で docs を1件作成し、currentDocId に設定。`myprompter.script` は削除
3. どちらも無ければ `DEFAULT_SCRIPT` で docs を1件作成

## エラー処理

- `myprompter.docs` のJSONパース失敗・配列でない場合: DEFAULT_SCRIPT 1件で作り直す（エラー表示なし）
- currentDocId がリストに無い場合: リスト先頭（最新）を選択
- localStorage 不可（プライベートモード等）: メモリ上のみで動作（リロードで消えるが、現行と同じ静かな縮退）

## テスト方針（現行どおり手動確認）

- 新規→入力→切替→戻すで内容が保たれる
- リロードで選択中原稿・リストが復元される
- 削除（通常／最後の1件）の挙動
- 旧データ（myprompter.script のみ）からの移行
- localStorage.clear() 後の初期状態
- プロンプター画面の動作が従来どおり（回帰確認）
